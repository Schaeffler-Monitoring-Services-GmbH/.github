# Support

## Where to get help

| I need… | Go to |
|---|---|
| To report a bug | Open an issue on the affected repository |
| To request a feature | Open an issue on the affected repository |
| To report a security issue | Follow [SECURITY.md](SECURITY.md) — never a public issue |
| To ask a usage question | Open a discussion on the affected repository, if enabled |

## Response expectations

This organization is maintained on a best-effort basis. Please include the
repository name, version/commit, and steps to reproduce so that issues can be
triaged quickly.
